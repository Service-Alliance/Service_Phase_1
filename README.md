== Getting started

1. Be sure to have **rvm** or **rbenv**
2. be sure to have **bundler gem** installed.
3. `bundle install` 
4. `rake db:setup`
5. Use `Procfile` to start application (lookup [Foreman](https://github.com/ddollar/foreman), 
[Hivemind](https://github.com/DarthSim/hivemind) or [Overmind](https://github.com/DarthSim/overmind))
